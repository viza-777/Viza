📘 How to Get Code

Follow these steps to generate perfect code chunks:

Step 1: Ask an AI Chatbot

Open ChatGPT, Claude, or your preferred AI assistant and tell it exactly what you want to create.

Step 2: Copy This Golden Rule

To make sure the AI gives you clean code that works instantly without annoying chatter, paste this instruction at the end of your message:

"Output ONLY a single block of valid HTML/CSS/JS code. Do not include markdown code block wrappers (like ```html), explanations, or introduction text. Start directly with the code."

Step 3: Paste and Run

Copy the code generated by the AI, paste it right into the VIZA canvas, and hit "Run Project" to watch it work!
